อัปโหลดโค้ดบอท

โพสต์จะขึ้นในหน้าแจก/ซื้อขายโค้ดบอท ให้ทุกคนเห็น

โพสต์เสียเงินจะซ่อนโค้ดจากสาธารณะ คุณส่งโค้ดให้ผู้ซื้อผ่านแชทได้

เว็บสาธารณะ

สร้างเว็บ HTML / CSS / JavaScript ออนไลน์ แชร์เป็นลิงก์ให้ใครก็เปิดได้

เว็บของสมาชิกทำงานในกล่องแยกที่เข้าถึงบัญชีของคุณไม่ได้ แต่ก็ควรระวัง อย่ากรอกรหัสผ่านหรือข้อมูลสำคัญในเว็บของคนอื่น

สร้างเว็บสาธารณะ

เขียนโค้ด ดูตัวอย่าง แล้วกดเผยแพร่ ได้ลิงก์ทันที

/s/
ใช้ a-z 0-9 และ - ยาว 3-30 ตัว ตั้งแล้วเปลี่ยนไม่ได้
ตัวอย่างนี้ทำงานในกล่องแยกแบบออฟไลน์ ห้องออนไลน์และที่เก็บข้อมูลจะทำงานเฉพาะในเครื่องคุณ
คู่มือ alexa API

ใช้ได้ทันทีในโค้ด JavaScript ของเว็บ ไม่ต้องติดตั้งอะไรเพิ่ม

room.on("message", function (m) { /* m.from, m.name, m.data */ });
room.send({ text: "สวัสดี" });
