ความเป็นส่วนตัวและความปลอดภัย

  • เก็บเฉพาะข้อมูลที่จำเป็นต่อการใช้งาน ได้แก่ ชื่อผู้ใช้ รหัสผ่าน (เก็บเป็นค่าแฮช) โค้ดและโทเคนบอทของคุณ โพสต์ และข้อความแชท
  • ไม่เก็บอีเมล เบอร์โทร หรือตำแหน่งที่ตั้ง และไม่บันทึก IP ลงข้อมูลของเว็บ
  • ไม่ขายและไม่แชร์ข้อมูลให้บุคคลภายนอก
  • บอทและโทเคนของคุณคนอื่นมองไม่เห็น แชทเห็นได้เฉพาะสองฝ่ายที่คุยกัน
หมายเหตุ: ผู้ดูแลเว็บเข้าถึงข้อมูลบนเซิร์ฟเวอร์ได้ในทางเทคนิค จึงไม่ควรส่งข้อมูลลับในแชท

บอทของคุณรันต่อเนื่องบนเซิร์ฟเวอร์ แม้ปิดหน้าเว็บหรือรีเว็บ

เพิ่มบอทตัวใหม่
บอทแต่ละตัวรันแยกกัน ไม่กวนกัน

ยังไม่ได้บันทึก
โทเคนที่ตั้งในแท็บตั้งค่า จะส่งให้โค้ดผ่านตัวแปร DISCORD_TOKEN
✅ พิมพ์แค่ชื่อไลบรารี ไม่ต้องใส่ pip install นำหน้า — ระบบตัดให้อัตโนมัติ
✅ รองรับหลายตัวพร้อมกัน คั่นด้วยช่องว่าง หรือ comma — เช่น discord.py aiohttp Pillow
✅ รองรับเวอร์ชัน เช่น pandas>=2.0 และ npm scope เช่น @discordjs/voice
หลังติดตั้งแล้ว ต้องกด "บันทึก + รันใหม่" เพื่อให้บอทโหลดไลบรารีใหม่

แจก/ซื้อขายโค้ดบอท

โค้ดที่สมาชิกนำมาแบ่งปัน

เว็บนี้ไม่รับชำระเงินแทน การซื้อขายตกลงกันเองระหว่างผู้ใช้ ระวังมิจฉาชีพ และตรวจโค้ดจากคนอื่นก่อนรันทุกครั้ง เพราะโค้ดที่ไม่ดีอาจขโมยโทเคนบอทของคุณได้

อัปโหลดโค้ดบอท

โพสต์จะขึ้นในหน้าแจก/ซื้อขายโค้ดบอท ให้ทุกคนเห็น

โพสต์เสียเงินจะซ่อนโค้ดจากสาธารณะ คุณส่งโค้ดให้ผู้ซื้อผ่านแชทได้
